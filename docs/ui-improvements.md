## 7. Firebase security, sessions and room cleanup
- `src/components/SessionProvider.tsx`, `src/core/sessionClock.ts`: Anonymous Auth keeps each guest UID. Browser-local activity state warns at 29 minutes and returns to the login form at 30 minutes; it pauses while another player must decide. This is a best-effort browser lock.
- `src/core/roomCommands.ts`, `src/core/gameCommands.ts`, `src/core/hostCommandProcessor.ts`, `src/core/gameEngine.ts`: room create/join/leave/kick/start/reset and game commands use Firestore transactions. Members submit immutable requests. The active room creator validates and applies them, writes a result and removes the request. The creator can see and alter hidden card state; the room UI now says to play with a trusted host.
- `src/components/Lobby.tsx`, `src/components/GameBoard.tsx`: room codes are eight allowed uppercase letters. The game shows when a request is waiting for the creator to return. A lobby-only foreground check closes rooms after 30 idle minutes and can resume cleanup after interruption or a member's return.
- `firestore.rules`: schema 3 rules deny unauthenticated access, room/invite enumeration, cross-player private reads and non-host gameplay writes. Members can access only a known invite and create their own join/action requests. Old room data is not migrated or deleted and is denied by the new rules.
- Firebase deployment remains Spark-only. `firebase.json` no longer configures Functions; the old Functions source tree remains unused in the workspace. No billing account or trial is involved. The separate unused Realtime Database keeps its deployed deny-all rules.
- Verification: final run passed six session-clock tests, eight game-engine tests, four Firestore client-command Emulator tests, five Firestore Rules Emulator tests, lint, TypeScript and production build. The live app loaded; a temporary two-guest smoke test confirmed room creation/join, private-card access, host-processed action, blocked non-host writes and idle cleanup. The temporary room and both guest accounts were deleted. The full Chromium UI fixture was not rerun in this final pass because Playwright is unavailable in the workspace; earlier fixture results are recorded above.
